# Butler Homes Website Concept

Premium static website concept for Butler Homes, focused on a cleaner custom home builder presence, richer photography, buyer-path interactions, and a polished Vercel-ready deployment.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual system
- `app.js` - interactions for filters, palettes, gallery preview, and calculators
- `vercel.json` - static deployment defaults

## Local Preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.
